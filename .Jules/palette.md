## 2025-07-08 - Empty States Need Clear Keyboard-Accessible Actions
**Learning:** When displaying an empty state for search results, users need a fast, explicit, and keyboard-accessible way to recover, such as a "Clear search" button that uses standard focus indicators.
**Action:** Always include a concrete reset path (e.g. `Clear search` button) with explicit `focus-visible:ring` styles in empty states instead of just static text.
